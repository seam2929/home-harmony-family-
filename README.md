# Home Harmony Family LLC — homepage demo

A responsive static homepage concept closely following the supplied full-page design. Open `index.html` in a browser to preview it. It uses no build tools or paid services. A few small photos are crops from the supplied low-resolution design image, so they may look soft when enlarged.

The site includes `services.html` (Services Hub), `service-area.html` (Service Area Hub), `about.html` (About Us), `blogs.html` (Blogs), and `contact.html` (Contact). The header navigation links to each hub. Hover over “Our Services” or “Service Area” to reveal its list. The Blogs page links to `st-louis-seasonal-cleaning.html`, a local guide using National Weather Service and City of St. Louis sources.

## Before showing it as a real business site

- The homepage shows the three Google Business Profile reviews supplied by the user.
- Confirm the phone number, current services, service area, and any credentials. The About page is written in first person using the owner and cleaner details supplied by the user. It avoids invented biographical events.
- The homepage and Contact page quote forms are visual demos and do not send or store submissions. The Services Hub quote link uses a placeholder email; replace it or connect a form service before launch.
- Replace the cropped preview photos with original high-resolution, approved photos before launch. The crops are only for matching the reference layout.
- The business address and service-area list were supplied by the user. Confirm any other business details before launch.

## Free ways to share

**Netlify Drop:** sign in to Netlify, choose Add new site / Deploy manually, and drag the `home-harmony-demo` folder onto the upload area. Netlify provides a shareable `netlify.app` address. Its free-plan details can change, so check the current plan before relying on it for an ongoing business site.

**GitHub Pages:** create a public GitHub repository, upload the files in this folder, then open Settings → Pages and publish from the `main` branch. GitHub Pages serves static files; it does not run WordPress. You get a `github.io` address.

**WordPress.com Free:** choose this if the goal is to work inside a WordPress dashboard. The free plan provides a `wordpress.com` subdomain, with plan limits. This static demo cannot be imported as a WordPress theme on the free plan; the page would need to be rebuilt with the available WordPress editor and blocks.

No domain or hosting purchase is needed for the demo. A self-hosted WordPress installation generally requires WordPress-compatible hosting; a custom domain is optional, but its registration typically costs money.
